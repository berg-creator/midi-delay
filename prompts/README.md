# Промпты для сессий

Работа нарезана на короткие сессии, чтобы каждая укладывалась в небольшой контекст.
Механика описана в [../CLAUDE.md](../CLAUDE.md), раздел «Эстафета промптов».

- `NEXT.md` — промпт для **следующей** сессии. Начинать работу отсюда.
- `_TEMPLATE.md` — шаблон, по которому пишется каждый следующий промпт.
- `PROGRESS.md` — что уже сделано, одна строка на задачу.
- `archive/` — отработанные промпты, в хронологическом порядке.

## Как запускать сессию

Открыть новую сессию Claude Code в корне репозитория и написать ровно одну фразу:

> Прочитай prompts/NEXT.md и выполни его.

Всё остальное агент возьмёт из `CLAUDE.md` и самого промпта. Историю прошлых сессий
читать не нужно — в этом весь смысл.

Нарезка — ориентир, а не закон. Если задача оказалась крупнее, чем выглядела, —
следующий промпт продолжает её, а не идёт дальше по таблице. Это нормально
и должно быть отмечено в разделе «Известные риски».

**Отдельно про S09.** Это точка честной проверки идеи. Если после первого живого рендера
результат не убеждает — правильный ход не «идти дальше по плану», а вернуться к ADR #6
и поменять движок питчинга. Дешевле переделать здесь, чем после M4.
