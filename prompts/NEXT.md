Если ответы в стартовом сообщении пустые — **окном вопросов в первую минуту**.

1. **BERG-S24: after чистый / в after тоже слышу / не слушал.**

   `action="https://app.kit.com/forms/<число>/subscriptions"`. Меню Kit может называться
   иначе — сверять по живому интерфейсу, не по этой строке.

## Что сделать
1. Вердикт — в `## [25]`.
2. Номер формы есть: вписать в `action`, сверить поле `email_address` и адрес с кодом
   встраивания, который отдаёт Kit (если отличается — прав Kit). Одна отправка своим адресом
   пользователя, с его согласия: письмо подтверждения пришло, адрес виден в Kit.
3. «Публикуем без формы» — секцию формы заменить строкой «Watch releases on GitHub»
   со ссылкой на страницу релизов; форма возвращается, когда будет номер.
4. Выкладка: workflow на `actions/upload-pages-artifact` + `actions/deploy-pages`, корень
   артефакта — `site/midi-delay` (адрес `berg-creator.github.io/midi-delay/`). Pages включить
   `gh api -X POST repos/berg-creator/midi-delay/pages -f build_type=workflow` — это публичная
   публикация, **сначала спросить**. Триггер — push в `site/**` и ручной запуск. Проверить,
   что страница открывается по адресу и картинка грузится.
5. «Не публикуем» — workflow не заводить: без включённых Pages он краснеет на каждом push.

1. **Вердикт уха отменяет замер.** «Слышу в after» — сайт откладывается.
2. **Промпт предыдущей сессии может быть неправ** — десять случаев. Адрес формы Kit

4. **Headless Chrome не уже 500 px и не завершается сам** — `## [49]`, «Сессия 25»;
   закрывать по своему `--user-data-dir`.
5. **Тексты страницы по-английски**, общение и коммиты — по-русски.
