# Как подать MIDI в плагин в FL Studio (macOS)

Проверено на FL Studio 20, macOS 26, 8 сентября 2026 года. Черновик — скриншоты добавляются
в задаче #32. Это главный барьер входа для пользователя: без этой инструкции плагин
выглядит сломанным, хотя работает.

## Шаг 0. Показать FL, где искать VST3

**FL сканирует только системный каталог** `/Library/Audio/Plug-Ins/VST3`.
Пользовательский `~/Library/Audio/Plug-Ins/VST3`, куда JUCE ставит плагин при сборке,
он игнорирует. Плагин собран и лежит на диске, но в списке его нет.

`Options → Manage plugins` → в списке путей поиска нажать `+` и добавить:

```
~/Library/Audio/Plug-Ins/VST3
```

Затем **Find installed plugins** с включённым пересканированием уже проверенных.

AU этой проблемы не имеет: `~/Library/Audio/Plug-Ins/Components` FL сканирует сам.

## Шаг 1. Плагин на аудио

Микшер → трек с вокалом → свободный слот эффекта → **MIDI Delay**.

## Шаг 2. Канал MIDI Out

Channel Rack → `+` → **MIDI Out**. Это генератор, но звука он не издаёт — только шлёт ноты.
Тишина от него это норма, а не поломка.

В его окне выставить **Port** — любое число, например `18`.

## Шаг 3. Связать порты

Окно плагина → **вторая иконка слева** в шапке (динамик с шестерёнкой, настройки обёртки FL)
→ секция **MIDI** → **Input port** → то же число, что в шаге 2.

Именно **Input**, не Output. Это ошибка номер один, и она молчаливая: всё выглядит
настроенным, а ноты уходят в никуда.

## Шаг 4. Ноты

Piano roll **канала MIDI Out** — не инструмента, не сэмплера. Ноты, нарисованные в FL Keys
или в сэмплерном канале, наружу не отправляются.

Канал должен быть в играющем паттерне. Play.

## Признак успеха

Надпись в окне плагина становится зелёной и показывает счётчик принятых нот.

## Если не работает

| Симптом | Причина |
|---|---|
| Плагина нет в списке | Не добавлен пользовательский путь VST3 — шаг 0 |
| Счётчик серый | Порты в MIDI Out и в обёртке не совпадают, либо заполнен Output вместо Input |
| Счётчик серый, порты верные | Ноты нарисованы не в канале MIDI Out |
| Видна старая версия плагина | FL держит библиотеку в памяти — **Reload plugin** в настройках обёртки |
| Странные символы в интерфейсе | Старая сборка в памяти, см. предыдущую строку |

## Почему это важно для продукта

Пять шагов и ручное сведение номеров портов — это то, на чём часть пользователей
бросит плагин, решив, что он не работает. Ровно поэтому в roadmap есть задача #36:
встроенный пиано-ролл убирает шаги 2–4 целиком.
