## Известные риски

1. **Вердикт уха отменяет замер.**

2. **Промпт предыдущей сессии может быть неправ** — семь случаев. Расходиться можно,
   записав почему.

3. **Ресурс в бандле после подписи ломает подпись.** Для #42 главное: только через CMake,
   `codesign --verify --strict` после.

4. **Смена идентификаторов после релиза — потеря проектов у пользователей.** До релиза
   бесплатна, но у самого пользователя уже есть проекты FL со старым кодом (сессия 19).

5. **Окна поверх работы пользователя** — `auval`, Gatekeeper, Installer.app только
   с предупреждением в чате до запуска.

6. **Пользователь переименовывает домашний каталог с `mke` на `Mike`.** Сборка не находит
   файлы — `rm -rf build` и заново.
